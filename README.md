# 🛡️ 坦克大战 · Battle Tanks

一个纯 HTML + Canvas 实现的经典坦克大战游戏，单文件、零依赖，打开即玩。

## 玩法

- 控制你的坦克，**保卫底部中央的基地**（旗帜），消灭所有来犯的敌方坦克。
- 敌人会从顶部三个位置持续出现，共三个关卡，难度逐关提升。
- 红色的「运输」敌人被击毁后会掉落道具。

## 操作

| 按键 | 功能 |
| --- | --- |
| `W A S D` / `方向键` | 移动 |
| `空格` / `J` | 射击 |
| `P` | 暂停 / 继续 |
| `M` | 静音 |
| `Enter` | 确认 / 开始 / 下一关 |

## 道具

- ⭐ **星星**：升级火力（更快的子弹、双发、可击穿钢板）
- ❤️ **生命**：+1 条命
- 🛡️ **护盾**：短暂无敌
- ❄️ **冰冻**：冻结所有敌人

## 敌人类型

| 类型 | 特点 | 分值 |
| --- | --- | --- |
| 普通 | 基础敌人 | 100 |
| 快速 | 移动很快 | 200 |
| 强力 | 子弹飞快 | 300 |
| 装甲 | 需要 3 发才能击毁 | 400 |
| 运输 | 击毁后掉落道具 | 500 |

## 运行
